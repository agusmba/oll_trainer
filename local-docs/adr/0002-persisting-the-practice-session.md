# Persisting the practice session

The Practice session — Mode, Goal, Weights and the Recap backlog — is stored in localStorage alongside the Selection, the times history and the Custom algs, so a reload lands the reader on the solve screen at the Goal they left, with the Recap backlog where it stopped. We decided this because a phone browser restores no form values across a reload: an Installed app that opens back on the case grid loses the reader's Goal, and a phone refresh in Recap restarts the whole Selection.

Weights come back only for the practice contract (Goal + Selection) they were earned against: the store carries the Goal and the Selection beside the pairs, and a store that does not match the current contract is no store, so the app restores uniform Weights. This is ADR-0001's guarantee kept in a new form. The clamp [1/8, 8] is unchanged, and a Weight earned under a different Goal cannot dominate a draw it was never earned for, because it never arrives. The Goal is app-persisted and the store is the truth: the goal input is repainted from it at load, which replaces ADR-0001's "adopt whatever the goal input shows" — that rule worked only on browsers that restore form values. The Recap backlog carries the Cases Recap has not replayed; Cases the Selection no longer holds are dropped from the carry, and an empty backlog is not a mode signal — Mode becomes Practice on the draw that empties it.

The Start cooldown: a start landing within 500 ms of the stop is ignored, measured from the stop, for key and touch alike, and the stopped time stays on screen. We decided this because the hand that stops the clock keeps moving — a second finger, or the same finger tapping twice, lands where the thumb already is. The press inside the window is spent, so its release begins a fresh gesture: the reader presses and releases again.

Considered: not persisting the Weights and the Goal, which is ADR-0001's original — rejected, because a phone reload wipes the steering signal and a week of practice resets to uniform on every refresh. Persisting the Weight map without the contract key — rejected, a Weight of 8 earned under a Goal of 1000 ms dominates every draw at a Goal of 2000 ms, the same cross-session landmine ADR-0001 refused. A 200 ms cooldown — rejected, it misses the slow tail of a two-finger stop. A 1000 ms cooldown — rejected, it eats deliberate starts in a fast cadence, where a reader who stops and starts within a second is solving, not flickering.
